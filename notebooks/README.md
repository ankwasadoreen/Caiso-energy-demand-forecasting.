# Notebooks

Recommended order:

1. `01_energy_data_exploration.ipynb`
2. `02_noaa_weather_integration.ipynb`

4. `04_random_forest_models.ipynb`
5. `05_xgboost_model.ipynb`
6. `06_model_comparison.ipynb`

Move your existing notebooks into this folder and rename them only if the mapping is clear.

Each notebook should:
- state its purpose at the top;
- use relative paths;
- avoid hard-coded Windows user paths;
- save reusable outputs to `../data/processed/` or `../outputs/`;
- be restart-and-run-all reproducible.
